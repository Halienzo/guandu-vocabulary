# 上师大官渡融合课程中心词汇学习系统 · V2.1

交付日期：2026年10月25日。单文件离线 HTML，无需安装依赖即可使用。

## 开始使用与迁移

1. 先在旧系统点击“备份”，保存学生档案 JSON。
2. 用 Chrome、Edge、Safari 或 Firefox 打开新版 HTML。不要直接在聊天附件预览器中运行。
3. 若新文件没有显示旧档案，在欢迎页“导入已有备份”或“档案与设置 → 导入备份”恢复。浏览器对不同文件地址的存储隔离策略不同，不能保证移动文件自动继承档案。
4. 新学生默认从打开当天的北京时间开始，每天6词，周末及节假日照常。旧学生开始日期、词序和记录保留。
5. 建议定期备份。不同设备之间通过备份迁移，不自动同步。

## 升级功能

- 所有正常词头恢复完整拼写，旁边新增“音节节奏”按钮。点击后在独立浮层显示森林绿色分读点并逐段高亮；关闭后回到原学习位置。支持重播、完整单词朗读和静态逐段查看；设置可关闭自动动画，也尊重系统减少动态效果偏好。动画是视觉记忆节拍，不模拟音频中的实际音节时长。
- 随机背词的每张词卡新增“检测当前词拼写”。检测时隐藏英文、音标、例句及音节提示，只保留中文与来源单元；提交后显示完整答案和音节按钮。空白不计错，错误进入原错题本，可重测、继续学习或完成整组后补测。
- 单词即练保留每次尝试，首测正确率不会因重测被覆盖；与整组正式考核分开统计。关闭弹窗或刷新保留草稿；主动返回查看答案则结束未提交尝试，不计成绩。每名学生独立保存，备份包含新记录。
- 纸质词测每次进入需输入已约定的教师密码；退出、刷新、切换学生、手动锁定都会清除本次授权和试卷缓存。生成、预览、A/B卷、答案、配置导入导出和打印由同一访问状态保护。
- 日历、词库的学习入口可选择原序或乱序。背诵中可仅打乱未完成词，完成后可整组乱序再背。
- 首页每日一词默认每学生每天固定，支持“换一个”、收藏、加入学习及完整词条。设置可改为重新打开随机探索。内置52组完整中英教学补充例句，避免把原文残句误当每日例句；不代表全部词条都已重写例句。
- 随机背词支持6、9、13、16、21、30、36、56、61词。可按分类、单元及未学/已学/收藏/错题/到期筛选。
- 同范围同一轮不重复抽词；末组不足时如实显示；切换题量继续原队列，切换范围分别保留队列。未完成分组和自评自动保存。
- 熟悉、生疏、困难是自评，不能替代拼写成绩。考核沿用正式与练习模式，错误进入错题本。
- 提前随机学习不会完成未来日历任务。旧版到期已学记录迁移到日历完成状态，未来已接触记录保留为提前学习；到计划日期后可用无提示正确拼写确认。

## 原功能和数据完整性

本次保留4225词条及全部原文字段，V2词库除版本号外逐字段一致，音节数据与每日例句未重写。每日6词日历、原书分类和单元、随机题量、整组考核、错题本、教师打印锁、PDF打印入口和备份功能均保留。单词即练不替代自评，不直接完成日历任务，也不计入正式考核成绩。旧档案中的音节点显示开关不再让词头拆开；新版只通过按钮展示分读。

## 音节数据的适用范围

绿色点是教学拼写分读辅助，不是IPA音节符号的逐字替代。英语拼写与语音不总是一一对应，英美口音和弱读也可能改变音节数量。

本版结合 eng-syl 的词典分读缓存、CMU Pronouncing Dictionary 的音节数量对照，以及专项校订。全库没有经过英语语音专家逐条认证：3416条采用词典缓存，751条含本次专项校订，14条采用单音节判断，44条含字母、缩写或特殊表达处理。每条都在“音节核验清单.tsv”中注明状态。

单音节词不加点；短语按组成词分读；缩写按字母名读。Edinburgh 等拼写难以对应语音的特殊地名保留原样并说明。temperature、interesting、secretary等可出现完整读法和省音差异。词库原始音标与原文仍保留，原有102项内容核对提示仍有效，默认不进入正式考核。遇到争议可在词条校订中修正分读；不会覆盖原文。

## 教师打印

进入“纸质词测”后输入教师密码（区分大小写），选择范围、题量、抽取方式、排列、题型、提示和栏数，生成固定试卷。打印对话框中选A4、100%缩放、关闭浏览器页眉页脚，可选择“另存为PDF”。学生卷和参考答案分别输出，A/B卷同题不同序。

密码使用SHA-256摘要校验，无需联网；授权不保存到浏览器档案。纯本地HTML的锁用于防止学生从正常界面擅自出卷，无法抵御开发者工具改代码、读取内置词库或截图等行为。它不是服务器权限系统。

## 开发与检查

完整包中的 vocab-v2.1/ 是新版源代码。Python3执行 `python build.py` 生成dist中的中文名HTML及index.html；Node.js执行 `node test.cjs` 运行81项检查（测试需要旁边的baseline-v1及baseline-v2目录作保全比对）。运行系统本身不需要Python或Node。

app.js保留原有业务流程，upgrade.js保留V2功能，interaction-v21.js与interaction-v21.css实现本次交互升级，dist/shell.html保留原排版并加入新版样式，dist/wordbank.json包含原词库、分读及每日例句。enrich.py是分读数据辅助构建脚本，额外依赖cmudict；成品已经包含所有必要数据，不需要运行它。research/仅保留用到的词典缓存子集、差异清单和许可证，不包含远程执行脚本。

校验完成：81项自动检查，包括原文逐字段不变、日历连续性、判分、错题、学生隔离、固定A/B卷、长题分页、音节可逆性、密码摘要、权限回收、分组无重复、尾组、旧档案迁移、每日词与备份结构。

本轮实际浏览器完成：完整词头显示、音节浮层与关闭返回、随机6词逐词检测、空白校验、错拼与正确重测、关闭和刷新后的草稿续写、整组完成后补测；另在390px宽度页面核验词卡、拼写面板及自动焦点。V2此前已完成整组考核与错题收录流程验收。尚未完成：本轮实际打印对话框/PDF输出的浏览器复核，以及多浏览器和实体手机测试。打印模板分页和题目完整性已在自动检查中验证。
